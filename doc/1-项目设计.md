1. 项目定位

做一个轻量 Windows 托盘程序，用来管理多个 SSH 服务器和多个本地端口转发。

核心目标：

多个服务器
每个服务器多个隧道
开机自启
托盘常驻
断线自动重连
一键打开本地管理页面

它不是 FinalShell，也不是 MobaXterm。它只专注一件事：

管理 SSH 本地端口转发
2. 技术栈定稿

建议使用：

Tauri 2
+ React
+ TypeScript
+ Rust 后端命令
+ Windows 自带 OpenSSH ssh.exe
+ JSON 配置文件

原因是 Tauri 支持用现有 Web 前端技术做界面，后端用 Rust 访问系统能力；官方文档也说明 Tauri 可以配合任意前端框架，并通过 Rust 后端与系统交互。

Tauri 2 也有系统托盘和开机自启插件，正好适合这个项目。

SSH 不自己实现，直接调用 Windows OpenSSH。微软文档说明 Windows 10 / Windows 11 的新版本包含基于 OpenSSH 的 SSH 客户端和服务端，OpenSSH 会加密客户端与服务端之间的通信。

3. 核心设计原则
3.1 一个服务器一个 SSH 进程

同一个服务器上的多个端口转发，不要开多个 SSH 连接。

正确做法：

主服务器
  ├─ 管理后台  127.0.0.1:18000 -> 127.0.0.1:8000
  ├─ 监控面板  127.0.0.1:18001 -> 127.0.0.1:9090
  └─ 数据库    127.0.0.1:18002 -> 127.0.0.1:3306

最终只启动一个 ssh.exe 进程

生成命令类似：

ssh -N ^
  -i "C:\Users\xxx\.ssh\id_ed25519" ^
  -o ServerAliveInterval=30 ^
  -o ServerAliveCountMax=3 ^
  -o ExitOnForwardFailure=yes ^
  -L 127.0.0.1:18000:127.0.0.1:8000 ^
  -L 127.0.0.1:18001:127.0.0.1:9090 ^
  -L 127.0.0.1:18002:127.0.0.1:3306 ^
  root@example.com ^
  -p 2222
3.2 不保存 SSH 密码

第一版只支持：

私钥登录
ssh-agent
无密码私钥 / 已加载到 agent 的私钥

不要在配置文件里保存服务器密码。

可以保存：

SSH 地址
SSH 端口
用户名
私钥路径
本地端口转发配置

不保存：

服务器密码
私钥 passphrase
root 密码
3.3 默认只监听 127.0.0.1

本地端口默认必须是：

127.0.0.1

不要默认监听：

0.0.0.0

否则局域网其他设备也可能访问你的本地转发端口。

6.3 SshCommandBuilder

负责把服务器配置转换成命令参数。

输入：

ServerConfig

输出：

ssh.exe 参数数组

不要直接拼接一整条字符串，应该生成参数列表，避免路径空格和转义问题。

伪代码：

args = [
  "-N",
  "-o", "ServerAliveInterval=30",
  "-o", "ServerAliveCountMax=3",
  "-o", "ExitOnForwardFailure=yes",
  "-o", "BatchMode=yes"
]

if private_key exists:
  args.push("-i")
  args.push(private_key)

for tunnel in enabled_tunnels:
  args.push("-L")
  args.push(format!(
    "{}:{}:{}:{}",
    tunnel.local_host,
    tunnel.local_port,
    tunnel.remote_host,
    tunnel.remote_port
  ))

args.push(format!("{}@{}", ssh_user, ssh_host))
args.push("-p")
args.push(ssh_port)

最终类似：

ssh.exe -N -L 127.0.0.1:18000:127.0.0.1:8000 root@example.com -p 2222

13. 自动重连设计

自动重连不是无限狂刷。

建议策略：

第一次失败：5 秒后重连
第二次失败：10 秒后重连
第三次失败：20 秒后重连
最高等待：60 秒
用户手动停止后，不自动重连

伪代码：

ssh 进程退出
if server.autoReconnect == false:
    状态 = 已停止
    return

if exit_reason == user_stop:
    状态 = 已停止
    return

状态 = 重连中
等待 reconnectDelay
重新启动 server
14. SSH 参数建议

默认参数：

-N
-o ServerAliveInterval=30
-o ServerAliveCountMax=3
-o ExitOnForwardFailure=yes
-o BatchMode=yes

含义：

-N：不打开远程 shell，只做隧道
ServerAliveInterval：保活
ServerAliveCountMax：失败几次后退出
ExitOnForwardFailure：端口转发失败就退出
BatchMode：避免卡住等待密码输入

第一版不建议默认加：

-o StrictHostKeyChecking=no

原因是这会降低安全性。

更好的方式是：

第一次连接让用户自己确认 known_hosts
或者提供“测试连接”按钮，弹出日志提示

# ssh-tunnel-tray

A lightweight Windows tray app for managing multiple SSH local port forwarding tunnels.

中文：一个轻量的 Windows 托盘 SSH 隧道管理器，支持多服务器、多端口转发、开机自启和自动重连。

## Features

- Multiple SSH servers
- Multiple local tunnels per server
- One SSH process per server
- System tray
- Auto start on login
- Auto reconnect
- Open local service with one click
- JSON config
- No password storage
